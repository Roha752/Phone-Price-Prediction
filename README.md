Used Phone Price Prediction (1M Dataset)An end-to-end Machine Learning project designed to accurately estimate the resale value of used smartphones based on physical condition, specs, hardware health, and market context using a dataset of 1,000,000 records.📌 Executive SummaryDetermining the fair market value of used electronics is challenging due to the complex interplay between hardware specifications, physical condition, device age, and market demand.This repository contains a full machine learning workflow—from extensive Exploratory Data Analysis (EDA) and data quality assurance to feature processing and regression model preparation—targeting resale_price across 1 million smartphone records.📊 Dataset OverviewThe dataset contains 1,000,000 rows and 28 columns, capturing a
